# 妙法蓮華經 · 線上讀本

單一 HTML 檔的《法華經》閱讀站台。以三層節點模型編排全經七卷二十八品，附白話語譯、要義提點、語音朗讀與經義問答。

底本：大正新脩大藏經 第九冊 no.262，姚秦三藏法師鳩摩羅什譯。
科判：天台智顗《法華文句》二門六段。

---

## 一、專案定位

本站不是全文電子藏經，也不取代 CBETA。它處理的是另一個問題：**《法華經》的結構如何被讀者看見。**

全經六萬九千餘字，跨七卷二十八品，義理骨架分跡門與本門兩重，七個譬喻散在七品之中而不相連。傳統的線性目錄無法呈現這些關係。本站把經文拆成可尋址的節點，讓門、科判段、品、長行／重頌四個層級各自成為導覽單位，七喻與版本異同則另立橫向索引層。

換言之，**結構先於內容**。經文可以逐步校錄補入，結構必須一次立對。

---

## 二、資料模型

### 縱向三層

第一層為門。跡門（開權顯實）涵蓋第一品至第十四品，本門（開跡顯本）涵蓋第十五品至第二十八品。

第二層為科判段。每門之下各分序分、正宗分、流通分，此即天台二門六段。

第三層為品。二十八品各繫屬於唯一的門與科判段，並標記所屬卷次（通行七卷本）。

品之下再分節點型別：長行為散說，重頌為韻誦。兩者在資料上是不同 type，在版面上以左側金線與字距區辨。此區分不可省略，因為法華通篇長行與重頌交替表述同一義理，混同即失真。

### 橫向兩層

法華七喻為跨品標籤層：火宅喻繫〈譬喻品第三〉，窮子喻繫〈信解品第四〉，藥草喻繫〈藥草喻品第五〉，化城喻繫〈化城喻品第七〉，衣珠喻繫〈五百弟子受記品第八〉，髻珠喻繫〈安樂行品第十四〉，醫子喻繫〈如來壽量品第十六〉。

版本註記為獨立欄位，不併入經文正文。凡涉譯本異同、品序爭議、補入沿革者皆入此欄。

### 節點欄位

每一品節點包含：品次、品名、所屬門、所屬科判段、卷次、語料狀態、段落陣列、七喻標籤、版本註記、白話語譯、要義提點。

段落陣列中每一段包含：型別（長行／重頌）、經文、段標（如「十如是」）。

## 三、語料狀態

本站經文為**節錄，非全文**。此為刻意設計，非未完成。

二十八品中，十八品已錄入代表性段落，標示「節錄」；十品未錄入，標示「待補」並顯示空狀態。首頁與內頁底部均顯示覆蓋率計數。

未錄入的品不以推測文字充填。理由是：由記憶重建古典文本必然產生竄字，而竄字一旦進入語料即難以偵測，其危害大於留白。空狀態頁面標明該品在底本中的定位（卷次、品次），供校錄時直接比對。

補入方式：以 T09 no.262 逐品比對後灌入 `PIN` 陣列對應節點的 `segs` 欄位，同時補 `gloss` 與 `points`，並將 `status` 由 `todo` 改為 `part` 或 `full`。

## 四、版本與校勘

以下六則已列入站內版本註記，並在目錄「版本與校勘」層可直接跳轉。

〈藥草喻品第五〉：梵本及隋《添品妙法蓮華經》於本品後半另有一段，羅什本闕。

〈提婆達多品第十二〉：羅什初譯本原無，係後人補入。《添品》本將其併入〈見寶塔品〉末，故《添品》本作二十七品，通行本作二十八品。此為全經版本差異最大之處，任何引用均應標明所據何本。

〈分別功德品第十七〉：天台科判以前十九行偈屬本門正宗分，其後屬本門流通分，本品跨兩段。站內歸屬正宗分，並於註記說明。

〈囑累品第二十二〉：羅什本置於第二十二，梵本及《添品》本置於全經之末。品序差異影響「二處三會」的收束方式。

〈觀世音菩薩普門品第二十五〉：長行為羅什所譯；末後重頌非羅什原譯，取隋闍那崛多、笈多《添品》譯文補入。本品自六朝以來單行流通，別題《觀音經》，多數讀者由此進入法華而未必讀過前二十四品。此為傳播史事實，不構成經義層級。

〈陀羅尼品第二十六〉：所載陀羅尼為梵語音譯，歷代刻本用字互有出入，校錄時必須以底本為準，不得以記憶補字。故本品列為待補。

另須註明：科判採天台《法華文句》，此為影響最廣者而非唯一，道生、吉藏另有判法。站內「總論」頁已載明此點。

## 五、功能

**三視圖切換。** 經文、白話語譯、要義提點三者共用同一節點，以分頁切換。白話語譯標示「本站自撰」，並附「非權威定本，經義以原文為準」之聲明。要義提點為結構性提示，不作宗教勸信。

**多層折疊目錄。** 漢堡選單以巢狀 `details` 實作，門、科判段、品三層可獨立折收。另有法華七喻與版本校勘兩組橫向索引，以及首頁、總論、抄經三個獨立入口。

**語音朗讀。** 使用瀏覽器 Web Speech API，語言設為 `zh-TW`，語速 0.86。可單品朗讀，亦可自當前品接續朗讀至末品。未錄入的品自動跳過。

**經義問答。** 呼叫 Anthropic Messages API，模型 `claude-sonnet-4-6`。系統指示要求：引經須有把握並標明品名，無把握則改以義理概述而不補字；涉科判須說明所據；涉版本問題須主動指出文獻背景；不作宗教勸信。此功能需在支援的執行環境中方能連線，離線時經文、語譯、要義不受影響。

**抄經頁。** 收錄開經偈，並明確標示其為誦經前通用偈語、相傳武則天所作，**非《法華經》正文**，不見於 T262 任何一品。此標示不可移除。

## 六、檔案與部署

`lotus-sutra.html` 為單一自足檔案，含全部樣式、資料與邏輯，無建置步驟。

外部相依僅 Google Fonts（Noto Serif TC、Noto Sans TC）。字體載入失敗時回退至系統襯線字體，不影響版面結構。

部署方式：置於任一靜態主機根目錄即可，GitHub Pages 可直接使用。若作為站台首頁，更名為 `index.html`。

瀏覽器支援：現代行動與桌面瀏覽器。已處理響應式版面、鍵盤焦點可見、`prefers-reduced-motion`。

## 七、待辦

依優先序排列。

其一，補齊十品待錄經文，以 T09 no.262 逐品校對。〈陀羅尼品〉須特別謹慎，音譯用字不得推測。

其二，已錄入的十八品目前僅為節錄，應逐步擴充至全品，並將 `status` 升級為 `full`。

其三，重頌的行段目前以換行符處理，未做偈句對齊。若需五言、七言的欄位對齊排版，須另立 `meter` 欄位。

其四，七喻索引目前僅指向所在品，未指向品內確切段落。段落層級的錨點尚未建立。

其五，〈普門品〉的單行需求應另設獨立深層連結，供單獨分享與持誦使用。

其六，跨段的〈從地踊出品〉與〈分別功德品〉目前各歸屬單一科判段並於註記說明，尚未實作一品跨兩段的顯示。
